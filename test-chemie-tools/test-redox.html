Oxidationszahlen bestimmen

Wähle eine Verbindung und tippe auf ein Atom — die Oxidationszahl wird angezeigt. Grün = positiv (oxidiert), rot = negativ (reduziert), grau = 0 (Element).

Verbindung wählen

Tippe auf ein Atom, um die Oxidationszahl zu sehen

Regeln zur Bestimmung

1
Element rein: Oxidationszahl = 0 (z. B. O₂, Fe, Cl₂)
2
Einatomige Ionen: Oxidationszahl = Ladung (Na⁺ → +1, Cl⁻ → −1, Fe³⁺ → +3)
3
F immer −1 in Verbindungen.
4
O meist −2. Ausnahme: Peroxide (H₂O₂ → O = −1), OF₂ → O = +2.
5
H meist +1. Ausnahme: Metallhydride wie NaH → H = −1.
6
Alkalimetalle immer +1, Erdalkali immer +2.
7
Summe aller Ox.-Zahlen = Gesamtladung des Moleküls/Ions.
Vorgehen: bekannte Werte einsetzen (F=−1, O=−2, H=+1) → Rest-Atom über Summen-Regel ausrechnen.

Eselsbrücke: OIL RIG — Oxidation Is Loss (von Elektronen), Reduction Is Gain. Oder deutsch: Oxidation = Ox.-Zahl steigt, Reduktion = sie sinkt.

Halbreaktionen ausgleichen

Jede Redoxreaktion zerfällt in zwei Halbreaktionen — Oxidation und Reduktion. Die Anzahl Elektronen muss gleich sein.

Beispiel wählen

Vorgehen Halbreaktionen:
1. Atom-Bilanz (außer O, H)
2. O mit H₂O ausgleichen
3. H mit H⁺ ausgleichen
4. Ladungs-Bilanz mit e⁻
5. Elektronen-Anzahl in beiden Reaktionen gleichsetzen → addieren.
In basischer Lösung: nach H⁺-Ausgleich auf beiden Seiten gleich viele OH⁻ addieren → H⁺ + OH⁻ = H₂O.
