Die wichtigsten Kräfte

Eine Kraft ist eine vektorielle Größe (Betrag + Richtung), die Bewegung ändert oder Verformung erzeugt. Einheit: Newton (N) = kg·m/s². Klick auf eine Kraft für den vollen Lehrbuch-Steckbrief.

Kraft als Vektor

Jede Kraft hat Betrag, Richtung und Angriffspunkt. Mehrere Kräfte addieren sich vektoriell zur resultierenden Kraft Fres.

Gleichgewicht: ΣF = 0 → keine Beschleunigung. Resultierende ≠ 0 → Beschleunigung in Richtung von Fres.

Newton'sche Gesetze

Drei einfache Sätze — die Grundlage der gesamten klassischen Mechanik. Jeder ist eine direkte Aussage über Kräfte und Bewegung.

1

Trägheitsprinzip

Ohne resultierende Kraft bleibt ein Körper in Ruhe oder bewegt sich gleichförmig geradlinig.

ΣF = 0 ⇒ v = const.

Beispiel: Eishockey-Puck gleitet (fast) reibungsfrei mit konstanter Geschwindigkeit weiter.

2

Aktionsprinzip

Beschleunigung ist proportional zur Kraft, in deren Richtung — umgekehrt proportional zur Masse.

F = m · a

Beispiel: 1 N beschleunigt 1 kg mit 1 m/s². Beim Auto: F = m·a → schwerere Autos brauchen mehr Kraft.

3

Wechselwirkungsprinzip

actio = reactio. Übt Körper A eine Kraft auf B aus, übt B eine gleich große, entgegengesetzte Kraft auf A aus.

FA→B = − FB→A

Beispiel: Du drückst die Erde mit deinem Gewicht — die Erde drückt mit gleicher Kraft auf dich (Normalkraft).

Konsequenzen

Trägheit braucht Masse: große Masse → schwer in Bewegung zu setzen, schwer abzubremsen (z. B. Lastwagen).
Impuls p = m·v: Das 2. Gesetz lautet allgemeiner F = dp/dt. Kraft ist Änderung des Impulses pro Zeit.
